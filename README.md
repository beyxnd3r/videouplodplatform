# РГЗ. Создание платформы для видео.

Это завершающая работа курса по Web-программированию. Она создана с помощью Python, Django,React, SQL.

## О чем эта работа 
Это платформа которая позволяет пользователям загружать, редактировать, и комментировать видео. На платформе реализована база данных пользователей и на платформе предусмотрено редактирование и удаление как видео так и комментариев только отправителем.

## Чем пользовался
Для бэкенда были использованы: Python, Django
Для фронта: React JS, CSS
БД: PosgreSQL 
и другие фреймворки для реализации основных функций платформы

## Запуск на пк
Для того чтобы запустить платформу нужно выполнить эти действия
1) Создаем виртуальное окружение: venv\Scripts\activate
   Устанавливаем: pip install -r requirements.txt, python manage.py migrate, python manage.py runserver

2) Далее установим npm install, npm start(проделать в папке с frontend). Если команды не работают установить дополнительные программы

## Команды API
Получение: GET /api/videos/ 
Загрузка: POST /api/videos/upload/ 
Редактирование: PUT /api/videos/<id>/edit/ 
Удаление: /api/videos/<id>/delete/
